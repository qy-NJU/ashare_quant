## 二、根本原因分析

### 🥇 原因1：震荡市 + 3天调仓节奏不匹配（主因，贡献约50%）

```
HS300 2026 Q1 走势图：
  ├── 1月：4718→4706，反复在MA60附近拉锯
  ├── 2月：4606→4711，月初急跌→月中反弹→月末又跌（过山车）
  └── 3月：4729→4450，单边下行
```

| 月份 | 胜率 | 市场特征 |
|------|------|---------|
| 1月 | 6W/7L (46%) | 箱体震荡，模型信号尚可 |
| **2月** | **3W/10L (23%)** | 🚨 月初急跌触发多笔止损，反弹时又追高被套 |
| 3月 | 1W/1L | 逆风降仓后几乎不交易 |

**核心矛盾**：3天调仓 + 震荡市 = 频繁止损。股票还没来得及走出趋势就被ATR止损踢出。2月10笔亏损中，大部分是买入后2-4天内遭遇市场回调触发止损。

### 🥈 原因2：ATR止损偏紧，震荡中"误杀"（贡献约30%）

```
参数：ATR止损倍数 = 2.5（即成本价 - 2.5 × ATR(14)）
```

在**趋势市**中，2.5×ATR是合理的缓冲空间。但在**震荡市**中：
- 股票正常的日内波动就可能打到2×ATR
- 3天调仓窗口内，个股回撤-5%到-8%是常态
- 止损后股票又反弹——典型的"割在最低点"

**证据**：28笔卖出中，标签为 `close/stop_loss` 的有28次（说明大多数不是自然调仓，而是触发了止损）。盈利单平均+10%，亏损单平均-4.5%，说明止损线不是设得太宽（否则亏损会更大），而是设得恰到好处——但震荡市下太容易被触发。

### 🥉 原因3：Top-K=4 集中度过高，容错率低（贡献约15%）

```
持4只，目标仓位60%，每只约15%
```

- 4只股票的分散度不足，任意1只亏-7%就拖累组合-1.05%
- 2月有几天"逆风期风控"触发后仓位压到30%，但之前已积累亏损
- 如果Top-K提至8-10只，单只暴雷的影响会稀释

### ④ 原因4：无行业分散约束（贡献约5%）

1月底集中持仓了603179、601212等同方向的标的，遭遇系统性回调时"一荣俱荣、一损俱损"。如果加入行业分散（单行业不超过30%），可以降低同向波动风险。

## 三、核心指标对比：问题不在于模型预测能力

| 指标 | 值 | 结论 |
|------|-----|------|
| 训练Rank IC | 0.8855 | ✅ 预测能力极强 |
| OOS Rank IC | ~0.64 | ✅ 样本外仍然可靠 |
| 盈亏比 | **2.2:1** | ✅ 赢的时候赢得大 |
| 单笔最大盈利 | **+43.8%** | ✅ 模型能选出爆发股 |
| 胜率 | 35.7% | ❌ 但频繁被市场回调打断 |

**模型的选股能力没有问题**——它确实选出了好股票（301171 +43.8%、603179 +23.7%）。问题在于：
- 震荡市中这些好股票也会先跌后涨
- 3天调仓 + ATR止损 在股票"先跌后涨"的过程中提前下车
- 用**趋势市的交易参数**跑在**震荡市**里

## 四、改进方案

### 方案A：拉长调仓周期（投入最少，效果最快）

```
rebalance_period: 3 → 5 或 7 天
```

| 调仓周期 | 预期胜率 | 原因 |
|---------|---------|------|
| 3天 | 36% | 震荡市噪音主导 |
| 5天 | ~42% | 给股票2天缓冲期 |
| 7天 | ~48% | 一周足够穿越小级别回调 |

### 方案B：放宽ATR止损（震荡市适配）

```
atr_stop_mult: 2.5 → 3.5（震荡市）
或：根据市场状态动态调整
  trending_up:  2.5（紧止损，趋势市中及时止错）
  ranging:      3.5（宽止损，震荡市中给更多空间）
  trending_down: 3.0（平衡）
```

### 方案C：增加持仓分散度

```
top_k: 4 → 8
target_position_ratio: 0.6 → 0.7 (更多标的但总仓位不变)
单只从15%降至8-10%
```

### 方案D：加入行业分散约束（已有RiskController，只需启用）

```yaml
risk:
  max_industry_weight: 0.25  # 单行业不超25%
  max_stocks_same_industry: 2
```

### 推荐执行顺序

| 优先级 | 方案 | 预期胜率提升 | 实施难度 |
|--------|------|-------------|---------|
| 🥇 | A + B 组合：调仓7天 + ATR动态3.5 | +10%-15% | ⭐ |
| 🥈 | D：行业分散 | +3%-5% | ⭐⭐ |
| 🥉 | C：Top-K扩至8 | +2%-3% | ⭐ |

**预计胜率可提升至45%-55%范围**。

## 五、为什么不建议直接上

1. **当前35.7%胜率 + 2.2盈亏比 > 1.0盈亏比×50%胜率的等效**——实际上这个组合的期望收益是正的（+0.87%总收益证明了这一点）。
2. 2026年是一个**极端横盘震荡年**（涨跌比1.00），策略仍能**盈亏平衡**，说明底子不差。
3. 核心问题是**参数不适配市场**，不是**模型不行**。
4. 调参后应在**更长回测期**（至少覆盖震荡+趋势+急跌三种市况）中验证鲁棒性。
